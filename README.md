# Simple Python Calculator

**Developer:** Hamdy Abou El Anein  
**Contact:** info@daylightlinux.ch  
**License:** No license file in the original repository; permission terms must be clarified before redistribution.

A modern Python 3 command-line calculator using `decimal.Decimal` for exact decimal operations. It supports interactive mode and single commands, with error handling for invalid input and division by zero.

```sh
python3 calc.py
python3 calc.py add 0.1 0.2
python3 calc.py divide 12 3
python3 -m unittest discover -s tests -v
```

The historical source is preserved on the [old branch](https://github.com/hamdyaea/SimplePythonCalucaltor/tree/old).
